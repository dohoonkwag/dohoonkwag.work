## Older Hardware

One of the biggest hurdles of this project was the hardware itself. The **NeuroSky MindWave Mobile 2** lacks recent developer support and modern documentation is scarce, so figuring out how to connect to the headset using an **Arduino Uno** and an **HC-05 module** was very difficult. I've explained all of the steps I took to connect to the headset on the GitHub repo.

## Pivoting from EEG to EOG

Originally, my goal was to write my own algorithms for calculating beta and alpha band power to calculate the how concentrated or relaxed the user was, rather than relying on the headset’s built-in concentration and meditation metrics. 

However, the headset relies on a single dry electrode placed on the forehead (the FP1 position), and separating the cortical signals from the facial muscle noise using just one sensor proved to be a little too difficult for me this time around. So, I pivoted to using **EOG (Electrooculography) signals**! Specifically, the massive voltage spikes generated by eyelid muscles during deliberate blinks.

## The Signal Processing Engine

To decode intentional blinks and ignore natural eye flutter, the Python backend runs a real-time digital signal processing (DSP) pipeline:

* **Bandpass Filtering:** The raw data is passed through a 1-15 Hz bandpass filter to remove DC drift and high-frequency noise.
* **Rolling Amplitude Detection:** A 250ms rolling window continuously calculates the peak-to-peak amplitude to detect the massive voltage swings characteristic of a blink.
* **Debouncing:** I observed that a blink often generates a sharp positive peak followed by a negative rebound. I wrote a custom hard-lockout debouncing algorithm to ensure that the trailing edge of a single blink doesn't get double-counted by the state machine.

## The Interface

Here's how the user can select a certain phrase:
* **Double-Blink:** Scrolls to the next available phrase.
* **Four-Blink Sequence:** Selects and speaks the current phrase. 

Once a phrase is selected, the system triggers Microsoft Edge-TTS to speak the phrase aloud in both English and Korean. The program also gives audio feedback (distinct sounds for scrolling, selecting, and discarding invalid patterns) so the user never actually has to look at a screen to know what the system is doing.

## Next Steps

Going forward, I'd like to explore better ways to filter out noise so I can eventually use custom meditation and concentration metrics for reliable control. Alternatively, the next step might be building a custom headset from scratch with an electrode placed in a much better spot for these metrics.
